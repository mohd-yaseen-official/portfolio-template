# 💼 Portfolio Homepage Clone

A simple and responsive homepage clone of a personal portfolio site, built using **HTML** and **SASS**. This project replicates the homepage section only, featuring a modern layout and elegant design.

## 🧩 Features

- Clean, single-page layout
- Responsive design using Flexbox and Grid
- Styled using SASS (SCSS syntax)
- Sections:
  - Hero Intro (Hello, I'm Lisa)
  - Services ("Things I Do")
  - Recent Work Gallery
  - Call to Action

## 🛠️ Built With

- HTML5  
- SASS (SCSS)

---
## 🚀 How to Run

### 1. Clone the repository:
   ```bash
   git clone https://github.com/mohd-yaseen-official/portfolio-template.git
   cd portfolio-template
   ```
### 2. Install SASS globally if not installed:

  ```bash
  npm install -g sass
  ```
### 3. Compile SASS to CSS:

  ```bash
  sass css/style.scss style.css
  ```
### 4. Open in Browser
Open **index.html** in your browser to view the homepage.
